# Nömrənin köçürülməsi (MNP)
> doc_id: number-porting · kateqoriya: köçürmə · qaydalar: —

## Proses
Başqa operatordan Səma-ya nömrə köçürmək üçün satış nöqtəsində şəxsiyyət vəsiqəsi ilə ərizə verilir. Köçürmə adətən **1–3 iş günü** çəkir: əvvəlki operator nömrəni azad edir, sonra nömrə Səma şəbəkəsində aktivləşir. Bu müddətdə köhnə SIM işləməyə davam edir.
Açar sözlər (RU): перенос номера, MNP, перейти с сохранением номера

## Gecikmə
Köçürmə 3 iş günündən çox gecikərsə, məsələ nömrə köçürmə üzrə mütəxəssisə ötürülür və 4 saat ərzində əlaqə saxlanılır.
Açar sözlər (RU): перенос номера задерживается, долго переносится номер
Danışıq dilində: nömrəmi Səma-ya keçirirəm, neçə gündür gözləyirəm, nömrə hələ keçməyib.
