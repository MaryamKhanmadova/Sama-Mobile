# İnternet işləmir: yoxlama siyahısı
> doc_id: data-troubleshooting · kateqoriya: texniki · qaydalar: —

## Addım-addım yoxlama
1. Balans və paket: paket aktivdirmi, həcmi və müddəti bitməyib? Balans müsbətdir?
2. Səma tətbiqində "Mobil internet" açarı: internet şəbəkə tərəfində söndürülə bilər. Müştəri mütəxəssisi onu aça bilər.
3. Telefonda "Mobil data" açıqdır, təyyarə rejimi söndürülüb.
4. Telefonu yenidən başladın.
5. Yeni telefonda APN ayarlarını yoxlayın (aşağıda).
6. Regionda qəza olub-olmadığını yoxlayın (bax: network-incidents).
Açar sözlər (RU): не работает интернет, нет интернета, мобильные данные

## APN ayarları
Ad: Səma Internet · APN: **sema.net** · istifadəçi adı və parol: boş · APN növü: default,supl.
- Android: Ayarlar → Şəbəkə və internet → Mobil şəbəkə → Giriş nöqtəsi adları (APN) → "+".
- iPhone: Ayarlar → Mobil rabitə → Mobil data şəbəkəsi.
Ayarları SMS ilə almaq üçün: *111*8# (müştəri mütəxəssisi də göndərə bilər). Yeni telefona keçəndə zəng işləyir, internet işləmirsə, səbəb adətən APN-dir.
Açar sözlər (RU): настройки APN, новый телефон, интернет не работает после смены телефона

## İnternet tez bitir
Video (xüsusən HD) saatda 1–3 GB sərf edir. Tətbiqdə istifadənin kateqoriyalar üzrə bölgüsünə baxmaq olar. Video keyfiyyətini azaltmaq və Wi-Fi-dan istifadə etmək tövsiyə olunur.
Açar sözlər (RU): быстро заканчивается интернет, кто-то ворует трафик
