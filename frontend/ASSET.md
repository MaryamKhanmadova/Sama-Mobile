# Agent avatar

`public/agent-avatar.png` was created with the built-in imagegen tool from the user-provided screenshot as a visual reference.

Prompt: Extract/recreate only the floating polished dark chrome robot face; front view, elongated oval head, navy-black chrome, cold silver left highlights, warm gold right cheek reflection, glowing white eyes, neutral mouth. Isolate on transparent background, with no UI, annotations, letters, shoulders or decorations.

## Current avatar

The active UI uses the user-supplied `public/avatar/maryam.glb` and `src/vendor/maryam/maryam-avatar.js`, copied unchanged from the Maryam handoff. `public/avatar/preview.png` is the fallback portrait. The previous robot image is retained as an unused legacy asset.
